Mengerjakan project web bukan hanya soal menulis kode. Selama bertahun-tahun, saya menemukan bahwa **kebiasaan kecil** justru paling menentukan apakah project selesai tepat waktu.

## 1. Mulai dari wireframe, bukan langsung kode

Sebelum membuka editor, gambar dulu struktur halaman. Bisa di kertas, Figma, atau sekadar daftar section. Ini mencegah perubahan besar di tengah jalan.

## 2. Batasi cakupan revisi sejak awal

Tulis daftar fitur dan batas revisi di kontrak atau kesepakatan. Kejelasan di awal menghindari konflik di akhir.

## 3. Gunakan sistem komponen

Komponen yang dipakai ulang menghemat waktu dan menjaga konsistensi desain. Inilah alasan saya memilih React untuk hampir semua project.

> Proyek yang "selesai" adalah proyek yang bisa dipelihara, bukan sekadar tampilannya benar.

## 4. Commit kecil dan sering

Git bukan hanya cadangan — commit kecil memudahkan menemukan penyebab bug dan memudahkan rollback.

## 5. Selalu uji di perangkat sungguhan

Jangan percaya sepenuhnya pada emulator. Buka project di HP kamu sendiri sebelum menyerahkan ke klien.

## Penutup

Kebiasaan-kebiasaan ini sederhana, tapi dampaknya besar. Mulai terapkan satu per satu — kamu akan melihat perbedaannya dalam beberapa minggu.
